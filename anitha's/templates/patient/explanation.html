How to Interpret Attention Heatmaps

Explainable AI maps neural network feature weights back to spatial coordinates on the chest radiograph. This reveals exactly which anatomical zones guided the Vision Transformer to its conclusion:

Red / Amber:
Primary Diagnostic Focus (Weight ≥ 0.80): Indicates areas where the model identified pathological tissue alterations, such as alveolar airspace opacification, fluid accumulation, or lobar consolidation characteristic of pneumonia.
Green / Yellow:
Secondary Contextual Focus (Weight 0.45 - 0.75): Encompasses supporting anatomical landmarks such as the cardiophrenic angles, vascular markings, and perihilar margins that the model evaluates to assess lung inflation symmetry.
Blue / Indigo:
Baseline Activation (Weight ≤ 0.35): Normal, aerated lung parenchyma or non-pulmonary background tissue (soft tissue cage, mediastinum, subdiaphragmatic space) with no acute radiographic abnormalities.

Transformer Math & Architecture
1. Patch Embedding:
An input image $x \in \mathbb{R}^{224 \times 224 \times 3}$ is partitioned into $N = 196$ flattened patches of size $P \times P = 16 \times 16$. Each patch is linearly projected into dimension $D = 192$.
2. [CLS] Token & 1D Positional Encodings:
A learnable classification token $z_0^0 = x_{\text{class}}$ is prepended to the sequence, and 1D positional embeddings $E_{\text{pos}} \in \mathbb{R}^{(N+1) \times D}$ are added to retain spatial coordinates.
3. Multi-Head Self-Attention (MHSA):
Each block calculates Query ($Q$), Key ($K$), and Value ($V$) projections:
Attention(Q, K, V) = Softmax(Q·K^T / √d_k) · V
4. Attention Rollout Formulation:
To track global token flow across all $L$ layers, we compute recursive matrix multiplication:
A_rollout = ∏ [0.5 · A_layer + 0.5 · Identity]
Taking row 0 yields the [CLS] token's exact attention weights for all 196 image patches.
