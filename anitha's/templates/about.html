MediLens AI: Explainable Medical Diagnosis using Vision Transformers & XAI

Department of Computer Science & Engineering (Artificial Intelligence & Machine Learning)

Project Problem Statement & Motivation

While deep convolutional neural networks (CNNs) have shown impressive diagnostic classification accuracy in chest radiography, their "black-box" nature presents a severe obstacle for clinical adoption. Radiologists and patients need to understand why a model arrives at a specific verdict. Furthermore, CNNs are inherently constrained by local kernel receptive fields, making it difficult to capture subtle global parenchymal asymmetries across bilateral lungs.

MediLens AI addresses these limitations by introducing a Vision Transformer (ViT-B/16) pipeline equipped with Self-Attention Rollout. By tokenizing the radiograph into 196 non-overlapping patches ($16 \times 16$ pixels), the model computes self-attention between every pair of patches across 6 transformer encoder layers. The attention rollout formulation subsequently reconstructs spatial activation heatmaps, providing verifiable radiologic explanations.

System Architecture Modules

  • Frontend Presentation Module: Responsive healthcare UI crafted with HTML5, CSS3 variables, JavaScript (ES6+), FontAwesome 6, and Chart.js for interactive evaluation graphs.
  • Backend REST & Web Module: Python Flask application factory handling role-based authentication, image validation, session management, and REST APIs.
  • AI & XAI Inference Engine: PyTorch Vision Transformer architecture with PatchEmbedding, Multi-Head Self-Attention, and recursive Attention Rollout generating Jet heatmaps.
  • Database & Audit Module: MySQL / SQLite persistence layer storing patient accounts, analysis records, doctor consultations, and security logs.
  • Clinical Report Generation Module: ReportLab PDF rendering engine creating clinical diagnostic summaries with embedded radiographs, confidence metrics, and doctor sign-off.
